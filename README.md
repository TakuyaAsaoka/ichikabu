# イチカブ

**一日一株。持ち株の決算・イベントカレンダー。**

自分の持ち株を登録すると、関連するイベントがカレンダーに並ぶ iOS アプリ。イベントは運用者が Web 管理 UI から**人力で登録**する。

| イベントの種別 | 例 |
|---|---|
| 銘柄イベント | 7203 の決算発表日 |
| 市場イベント | FOMC・日銀会合・米CPI・予算案 |
| **テーマイベント** | ドローンドミナンス採用決定（テーマに紐づく銘柄群に効く） |

**価値の中心はテーマイベント。** 決算日は証券会社アプリに既にあり差がつかない。「このテーマのこのイベントでこの銘柄が動く」という紐付けは自動取得できず、どこにも売っていない。人力の管理 UI はつなぎではなく製品の中身。

株価・損益・チャート・売買機能は持たない。**予測も助言もしない。**

## 構成

```
openapi.yaml   API契約の唯一の正（手書き）
ios/           Swift + SwiftUI
server/        Next.js（管理UI + API Route Handlers）
```

pnpm workspace も Turbo も入れない。ただのディレクトリ2つ。1リポジトリにする理由は、Swift↔TS で型共有の自動検知が効かない以上、契約のズレを捕まえる手段が「同じ PR で両側の差分が並んで見える」ことしか残らないため。

## マスコット

**ケッサンショウオ**（決算 → ケッサン → サンショウウオ）。じっと動かず、ずっと見ている。売買も予測もせず予定を眺めるだけ、というこのアプリの性格そのもの。
